# アーキテクチャ比較

アーキテクチャパターンごとにディレクトリを分け、実装を比較できるようにする。

ビルド・実行には[.NET SDKのセットアップ](SETUP.md)が必要。

| アーキテクチャ | 実現方法 | ディレクトリ |
|---|---|---|
| レイヤードアーキテクチャ | ASP.NET Core Web API | [layered](layered) |
| クリーンアーキテクチャ | ASP.NET Core Web API | [clean](clean) |

各ディレクトリは独立したソリューションになっている。同じ題材（DeepSORVFのAIS処理→検出→追跡→融合）を
パターンごとに実装し、構造の違いとその影響を比較するのが目的なので、パターン間でコードは共有しない。
