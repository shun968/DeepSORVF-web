# サンプルデータ

`task run` で起動したAPIの動作確認用の**合成データ**。FVesselデータセットの実データではない
（実データはHugging Faceで配布されているが、このリポジトリのサンドボックスは当該ホストへの
アクセスを許可していないため取得していない）。

ファイル形式はPython版（`utils/file_read.py` / `utils/AIS_utils.py`）と同じ。

- `camera.txt`: カメラパラメータ11値を1行で持つ。経度121.5・緯度29.87の地点から**真東**を向き、
  下向き5°、水面上20m、画角55°x35°、1920x1080相当（主点960,540）
- `ais/<yyyy_MM_dd_HH_mm_ss>.csv`: 1秒1ファイル。列は `mmsi,lon,lat,speed,course,heading,type,timestamp`
  （timestampはUNIXミリ秒）

`ais/2021_01_01_12_00_00.csv` に置いた4隻は、パイプラインの各段を1回のリクエストで観察できるように
選んである。

| MMSI | カメラからの位置 | 期待される扱い |
|---|---|---|
| 431234567 | 真東 800m | 視野内。ピクセル座標に投影される |
| 431987654 | 東北東 1500m | 同上（画面左寄りに出る） |
| 431555001 | 真北 900m | 水平視野外（`data_filter`の`visTraj_del`相当）なので投影されない |
| 431222999 | 真東 4500m | 2海里（約3704m）の距離ゲート外なので粗選別で落ちる |

AISファイルは12:00:00の1秒分しか無いため、2フレーム目以降は**デッドレコニング（位置推算）**で
位置が更新される。`frameIntervalSeconds` を10秒程度にすると、船が進んでピクセル座標が変化するのが
分かりやすい。動画は無いので、検出・追跡・融合は行われない。
